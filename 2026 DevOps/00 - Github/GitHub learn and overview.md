
### Why git exists:

* Git is a version control system of code, it will resolve lot of issue
	* Multiple developer can work at same time
	* We can revert the code if any issue can happen on new update
	* Help to track changes in source code

### Core concept:
* Instead of saving multiple files to save to code that when upgrade we can save in single project folder and takes snapshot of code every time when save the process

### 3 Main states of files:
- Modified: You have changed file but not saved in git repo
- Staged: You have marked modified file to be included on next snapshot
- Committed: The snapshot is permanently and safely save in git history
