
`It happens when git cannot automatically merge two branches because the same line of code was changed in different ways, or a file was deleted in on branch but edited in another`

### 🛠️ What a Conflict Looks Like:

```
<<<<<<< HEAD
This is the code currently on your active branch (e.g., main).
=======
This is the conflicting code from the branch you are trying to merge.
>>>>>>> feature-branch
```
